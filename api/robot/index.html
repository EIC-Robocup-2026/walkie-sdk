    WalkieRobot¶

    Main entry point for the Walkie SDK. Wraps all robot subsystems into a single object.

    WalkieRobot(ip, ros_protocol='rosbridge', ros_port=9090, camera_protocol='zenoh', camera_port=7447, timeout=10.0, namespace='', arm_mode='custom_ik', arm_target_pose_topic='/target_pose', ws_port=None, enable_camera=True) ¶

    Main SDK class for controlling a Walkie robot.

    Auto-connects to the robot on initialization and provides access to: - .nav: Navigation controls (go_to, cancel, stop) - .status: Telemetry data (get_position, get_velocity) - .camera: Camera frames (get_frame) - if enabled - .viz: Visualization markers for RViz2 (draw_marker, clear_markers)

    Parameters:

    Name Type Description Default
    ip str

    Robot IP address or hostname

    		 required
    ros_protocol str

    ROS communication protocol to use: - "rosbridge": WebSocket via roslibpy (default, no ROS2 required) - "zenoh": Zenoh DDS bridge (no ROS2 required) - "auto": Auto-detect best available protocol

    		 'rosbridge'
    ros_port int

    Port for ROS transport (default: 9090 for rosbridge)

    		 9090
    camera_protocol str

    Camera stream protocol to use: - "zenoh": Zenoh video stream (default) - "usb": Local USB camera via OpenCV - "none": Disable camera functionality

    		 'zenoh'
    camera_port int

    Port for camera stream

    		 7447
    timeout float

    Connection timeout in seconds (default: 10.0)

    		 10.0
    namespace str

    ROS namespace for topics/actions (default: "" = no namespace)

    		 ''
    arm_mode str

    Default arm control mode: - "moveit": MoveIt motion planning (default) - "custom_ik": Publish Pose to custom IK solver for teleop

    		 'custom_ik'
    arm_target_pose_topic str

    Topic for custom IK mode (default: "/target_pose")

    		 '/target_pose'

    Raises:

    Type Description
    ConnectionError

    If connection to robot fails
    ValueError

    If invalid protocol specified
    Example 
    from walkie_sdk import WalkieRobot

# Default: WebSocket + Zenoh camera (no ROS2 needed on client)
bot = WalkieRobot(ip="192.168.1.100")

bot.status.get_position()
# {'x': 0.0, 'y': 0.0, 'heading': 0.0}

bot.nav.go_to(x=2.0, y=1.0, heading=0.0)
# 'SUCCEEDED'

bot.disconnect()

# With namespace:
bot = WalkieRobot(ip="192.168.1.100", namespace="robot1")
# Topics will be /robot1/odom, /robot1/cmd_vel, etc.

    nav property ¶

    Navigation controller.

    Provides: - go_to(x, y, heading, blocking=True): Navigate to pose - cancel(): Cancel current navigation - stop(): Emergency stop

    status property ¶

    Telemetry/status provider.

    Provides: - get_position(): Get current pose {x, y, heading} - get_velocity(): Get current velocity {linear, angular}

    camera property ¶

    Camera interface (if enabled).

    Provides: - get_frame(): Get latest camera frame as numpy array - is_streaming: Check if camera is active

    Returns None if camera was disabled or failed to connect.

    cameras property ¶

    Multi-camera interface (if enabled).

    Provides access to multiple cameras on the robot: - get_head_frame(): Get head/front camera frame - get_left_frame(): Get left wrist camera frame - get_right_frame(): Get right wrist camera frame - get_all_frames(): Get all camera frames as dict - get_frame(camera_name): Get frame from specific camera

    Returns None if camera was disabled or failed to connect.

    Example 
    frames = bot.cameras.get_all_frames()
head = bot.cameras.get_frame("head")

    arm property ¶

    Arm controller.

    Provides: - set_joint_positions(left_arm, right_arm, ...): Set joint positions - set_joint_velocities(left_arm, right_arm, ...): Set joint velocities - set_joint_torques(left_arm, right_arm, ...): Set joint torques - get_joint_states(): Get current joint states

    viz property ¶

    Visualization marker controller for RViz2.

Provides:
- draw_marker(position, quaternion, frame_id, ...): Publish a single marker
- draw_markers(markers): Publish multiple markers as MarkerArray
- update_marker(marker_id, ...): Update an existing marker
- delete_marker(marker_id): Delete a specific marker
- clear_markers(): Remove all markers
- draw_pose(position, quaternion, frame_id, topic): Publish a PoseStamped
- update_pose(position, quaternion, topic): Update an existing PoseStamped
    Example 
    bot.viz.draw_marker([1.0, 2.0, 0.0])  # Red arrow
bot.viz.draw_pose([1.0, 2.0, 0.0])    # Pose triad

    tools property ¶

    Tools module for utility functions.

    ip property ¶

    Robot IP address.

    namespace property writable ¶

    Current ROS namespace for topics/actions.

    is_connected property ¶

    Check if connected to robot.

    ros_protocol property ¶

    Get the ROS protocol being used.

    camera_protocol property ¶

    Get the camera protocol being used.

    disconnect() ¶

    Disconnect from the robot.

    Stops all subscriptions, closes camera stream, and terminates ROS transport connection. Safe to call multiple times.

    Name Type Description Default

    [x, y, z] position in the reference frame.

    		 required
    quaternion

    [x, y, z, w] orientation quaternion. Defaults to identity.

    		 None
    frame_id str

    TF reference frame (default: "base_link").

    		 'base_link'
    **kwargs

    Additional marker options (marker_type, scale, color, etc.)

    		 {}

    Returns:

    Type Description
    int

    The marker ID that was used.
    Example 
    bot.draw_marker([1.0, 2.0, 0.0])

    update_marker(marker_id, position=None, quaternion=None, **kwargs) ¶

    Convenience method to update an existing visualization marker.

    Only pass the fields you want to change. Everything else is kept from the original draw_marker() call.

    Shortcut for bot.viz.update_marker(). See Visualization.update_marker() for full parameter documentation.

    Parameters:

    Name Type Description Default
    marker_id int

    ID of the marker to update.

    		 required
    position

    New [x, y, z] position (or None to keep current).

    		 None
    quaternion

    New [x, y, z, w] orientation (or None to keep current).

    		 None
    **kwargs

    Additional fields to update (frame_id, scale, color, etc.)

    		 {}
    Example 
    mid = bot.draw_marker([0, 0, 0])
bot.update_marker(mid, position=[1.0, 2.0, 0.0])
